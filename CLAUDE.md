# Project notes

## Scope

This repository (`agency-agents`) is a collection of AI agent/subagent definitions
(prompts, configs, install tooling) organized by department (engineering,
marketing, finance, healthcare, etc.). It is not a place for legal work.

Do not use this repository for legal analysis tasks (e.g. Turkish labor law
/ iş hukuku case evaluations, contract review, legal opinions). If such a
request comes in against this repo, point out the mismatch and suggest
handling it outside the repo (plain chat, or a separate document) instead of
treating it as a coding/repo task.
